## Kenneth O. May reference

The repository records bibliographic links for Kenneth O. May's 1966 work used as mathematical context. The paper itself is not vendored into the Android build and is not relicensed here.

## Generated orthant artifact

`src/Orthant.idric` is the maintained mathematical source for the checked-in C geometry header used by Android. The generated header is kept reproducible so the F-Droid Android build does not need to download or bootstrap a compiler.

## Platform and toolchain

Android SDK/NDK components, Gradle, CMake, native_app_glue, system libraries, and OpenGL ES interfaces are external to this repository and remain under their upstream terms.
